# 小型画面向けの画面設計

2026-09-24。主対象は小型ノートPCの 1024×600〜1366×768。文字の読みやすさを維持しつつ、検索から文字選択・編集・コピーまでページを上下に移動せず使える構成にする。

## 常時表示するもの

- 上端: アプリ名、ツール切替、メニュー。検索欄は独立した1行。
- 文字表上部: 面とブロックの選択、一覧・表示設定への入口。範囲・件数、未割当表示、ページ送りを表示。
- 中央: 文字表。初期文字サイズ 30px、1ページ128文字を維持。収まりきらない分は文字表の内側でスクロールする。
- 右側: 選択文字、コード、名称、追加・コピー、基本属性。長い属性や Unihan はこの欄だけでスクロールする。
- 下端: 編集テキスト、文字数、出力形式、コピー、変換・保存への入口。

大きなロゴ、説明用キャッチコピー、英語の補助見出し、繰り返される操作説明、常設の左サイドバー・フッターを取り除いた。使い方、版情報、出典はメニューから確認できる。

## 必要なときに開くもの

| 入口 | 操作 |
| --- | --- |
| 詳細検索 | 属性条件・別名・単語全体での検索。既定と異なる条件数をボタンに表示 |
| コード指定 | 16進/10進コードポイントへの移動 |
| 一覧 | 全面のブロック名の絞り込み、面選択欄の予約面表示切替 |
| 表示設定 | フォント、文字サイズ、色分け |
| 変換・保存 | 正規化、大小文字、方向、検索、元に戻す、クリア、切り取り、ファイル保存、文字単位確認 |
| メニュー | 使い方、アプリについて、クレジット、配色、デスクトップの最前面表示 |

ブロック一覧は現在の面に関係なく、全面のブロックをコードポイント順に表示する。別の面のブロックを選ぶと面と選択文字も切り替わる。上部のドロップダウンは選択中の面のブロックだけを表示し、一覧の絞り込みには連動しない。

操作用のポップオーバーは外側クリック・Escape・同じ入口の再押下で閉じる。Escape では入口へフォーカスを戻す。アプリ情報・使い方・狭い画面の文字情報はモーダルで開き、本文だけをスクロールする。

## 画面幅への適応

701px 以上では文字情報を右側に置き、700px 以下では選択文字の要約と「文字情報」ボタンに切り替える。600px 以下では文字表を16列から8列へ変更し、上下・Home・Endキーの移動量も列数に合わせる。ツールのプルダウンからすべてのタブへ移動できる。

Electron の初期ウィンドウは最大 1200×760、実際の画面の作業領域を上限にする。ブラウザやウィンドウ装飾による高さの減少を考慮し、1024×500 の内容領域でも検索・ページ送り・編集欄が収まることを検証する。

## 実装と検証

`100dvh` の縦方向レイアウトで検索と編集欄の場所を確保し、中央の領域を可変にする。CSS の `min-height: 0` と独立したスクロール領域を使用。文字サイズプレビューの局所 state / Context を維持し、連続入力で App や文字セル生成を再実行しない。

`tests/e2e/compact.spec.ts` で 1024×600・1366×768・1024×500、390×844 と画面リサイズを検証する。入力・挿入・ページ送り、最大文字サイズ、長い文字情報、変換出力、フォント・絵文字への移動、ポップオーバーとダイアログのフォーカス復帰を含む。画面撮影は `node tools/capture-ui.mjs`、性能計測は `node tools/benchmark-size.mjs`。

参考: [MDN: Popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API/Using)、[MDN: matchMedia](https://developer.mozilla.org/en-US/docs/Web/API/Window/matchMedia)。
