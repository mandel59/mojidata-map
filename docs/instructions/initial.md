現在メンテナンスされていない [https://www.babelstone.co.uk/Software/BabelMap.html](https://www.babelstone.co.uk/Software/BabelMap.html) のクローンアプリとして、 Mojidata Map を開発する。 
BabelMapと同等の機能を提供する。var/BabelMapBeta.zip を解析して仕様を把握する。
UIは完全コピーにせず、使いやすさを考慮して改善してよい。
Windowsアプリを主なターゲットとするが、できればクロスプラットフォーム対応やWebアプリ対応も入れたい。適宜実装技術を検討・選定する。
