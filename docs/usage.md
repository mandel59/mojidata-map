# 使い方

## 言語と基本操作

右上のメニューの「言語 / Language」から日本語・英語を切り替えられます。選択した言語は次回起動時にも保持します。Unicode の正式な文字名など、データそのものは翻訳しません。実装方針は[多言語対応](intl.md)を参照してください。

- 文字をクリックすると情報を表示し、ダブルクリック / Enter で編集バッファに追加します。
- 文字・絵文字とも矢印キーで選択を移動し、Home / End で行の先頭・末尾へ移動できます。Tab は一覧内の選択項目1件を経由します。
- Page Up / Page Down で文字マップ・検索結果・ブックマーク・絵文字一覧のページを送れます。入力欄では通常のキー操作を維持します。
- Ctrl+Shift+F（macOS は Cmd+Option+Shift+F）は文字検索へ移動します。Ctrl/Cmd+F はブラウザの既定操作を妨げません。
- ☆ でブックマークを保存します。設定・ブックマーク・編集テキストは端末のローカルストレージへ保存します。ファイルから追加したフォントはそのセッションのみ有効です。

文字表の「◌」「␣」「·」等は結合文字・空白・未割当の表示補助です。コピーされる文字には補助記号は含まれません。サロゲートは情報を閲覧できますが文字として挿入できません。フォントフォールバックを伴う通常表示と、読み込んだフォントの厳密な cmap / 輪郭解析は異なります。

## 文字の移動と検索

- 名前（英語）、別名、文字、`U+1F600` のようなコードポイントで検索できます。「文字検索」の縦タブからカテゴリ、スクリプト、追加版、ブロック、面、二値属性、Bidi、結合クラス、漢字の部首・内画数・総画数・読みを条件として追加できます。二値属性は複数追加でき、すべてに一致する文字を検索します。適用中の条件はチップで確認・個別解除できます。
- 文字マップの検索欄は現在位置の次の一致文字へ移動します。同じ条件で検索ボタンまたは Enter を繰り返すと、末尾から先頭へ戻って巡回します。文字検索タブの条件・結果は保持されます。
- 文字表上部の Unicode 面・ブロック選択、または「コード指定」の16進 / 10進入力で移動します。補助面・私用面・予約面も閲覧できます。
- 「漢字 (Unihan)」で部首・内画数・総画数、言語別の読み・意味、IRG出典、辞書・字形、異体字、字種、数値を AND で組み合わせられます。総画数は別の数え方も含めて照合し（例: 卿は10画・12画）、部首の枝番も区別できます。出典番号は前方一致、`*` は登録あり、異体字は参照先の文字またはコードポイントで検索します。
- 「東アジア (UAX #60)」で西夏文字・女真文字・女書・小篆を検索できます。例: 西夏文字の出典番号 `L2008-0008`、女書の読本番号 `36.02`、小篆に対応する漢字「一」。西夏文字・女真文字の画数は部首を含む総画数です。文字情報・JSON 保存に出典の元データも含めます。項目の選定と照合方法は[検索条件の優先度](investigations/property-search-priorities.md)を参照してください。

## 文字情報と編集バッファ

- 文字情報には「標準化異体字シーケンス（SVS）・絵文字の表示形式」に加え、「漢字異体字シーケンス（IVS）」を表示します。IVS のコードポイント列と IVD のコレクション名・登録識別子を確認し、クリックで列全体を編集バッファへ追加できます。同じ IVS の複数コレクションへの登録は1項目にまとめています。
- 編集バッファへ貼り付けて F2 を押すと、カーソル位置の文字に移動します。「変換・保存」から NFC / NFD / NFKC / NFKD、大小文字変換、左右方向、文字単位の確認、UTF-8 / UTF-16 保存を利用できます。
- 出力形式を変更すると、NCR・HTML・UCN・JavaScript・UTF-8 / 16 / 32 の表現をコピーできます。元の編集テキストは保持します。
- 右上の「メニュー」内にある「アプリについて」「クレジット」から、アプリとデータのバージョン、出典、利用ライブラリのライセンスを確認できます。デスクトップ版では「ヘルプ」メニューからも開けます。

## 絵文字

「絵文字検索」では名前・グループで絵文字を検索できます。国旗・肌色・ZWJ を含む完全なシーケンスを選び、文字と同じ位置のプレビューから追加・コピーできます。1ページ64件を表示します。一覧のセル密度・文字サイズ設定は文字マップと共通で、検索欄とページ送りを固定して一覧だけスクロールできます。

## 表示フォント

- 文字の既定書体は `serif` です。保存済みのフォント指定を優先します。共通の表示フォントとブロックごとのフォントは「表示設定」で変更します。
- Chromium の自動フォールバックで欠字になる場合は、「表示設定」→「補完用フォントを取得」を実行します。許可した端末フォントの収録範囲から補完用の合成フォントを作り、文字表・検索結果・ブックマーク・詳細・編集バッファに適用します。指定フォントを優先し、拡張 J に限らず補助面や私用文字も対象にします。対応フォントが端末に必要です。有効化の設定は保存され、次回は権限が維持されていれば再取得します。フォントの解析は端末内で行います。

## フォント解析

フォントファイルから cmap、収録文字、メタデータ、SVG 輪郭、OpenType のグリフ ID・位置を確認できます。ファイルは外部へ送信しません。フォント列挙は対応環境で許可した場合のみ利用できます。

### グリフマップ

- 「表示範囲」で Unicode コードポイントやブロック別にプレビューします。
- 「異体字列」の「SVS」「IVS」では、そのフォントの cmap に対応がある登録済みシーケンスだけを128件ずつ表示します。同じグリフを使う列も個別に選択・追加・コピーできます。
- 「全グリフ」「単一文字の割当なし」では、VS 専用字形・合字・代替字形などを Glyph ID 順に表示できます。選択した文字の輪郭・Glyph ID・グリフ名・寸法を確認し、追加・コピー・SVG / PNG 保存ができます。狭い画面では下部の「グリフ情報」から詳細を開きます。
- 一覧は128件ごとにページ送りでき、矢印キーで選択、Enter で編集欄へ追加できます。Glyph ID（10進数）で移動し、「対応する文字・リガチャ・VS」で単一文字・GSUB 合字の文字列候補・VS 列を選んで追加・コピーできます。
- 合字の逆引きは通常の横書きで有効な feature に限定し、縦書き・任意の装飾字形などを除外します。文字体系・言語・文脈によって実際の字形が変わります。
- グリフ名がない場合に限り、対応する Unicode 文字名を見出しに表示します。リガチャの文字列が Unicode Named Sequences と完全一致する場合は、その名前を使います。フォント自身のグリフ名がある場合は優先します。SVS など Unicode データに登録された VS 列は、グリフ情報にシーケンス名も表示します。
- 「グリフ置換（GSUB）」を開くと、選択グリフを置換元・置換先に含む規則の字形・GID・feature・Lookup を確認できます。この欄は縦書きなど任意 feature も含みます。
- 文字列の対応がないグリフは輪郭の閲覧・SVG / PNG 保存に対応します。

フォントタブで選択・読み込みしたフォントは、そのタブの入力欄・プレビューと PNG 出力に使用し、文字マップ・文字検索・編集欄などの表示フォント設定は変更しません。

### サンプル

「サンプル」は選択フォントで入力でき、収録数と OpenType のグリフ配置を確認できます。Glyph ID をクリックするとグリフマップの「全グリフ」でその字形の情報を開きます。Glyph ID の隣に実際のグリフを表示し、未収録のグリフを強調します。「編集バッファから読み込む」で現在のテキストをコピーして調べられます。入力はバッファと独立し、フォント切替後も保持します。制御文字・表示調整用文字・不正サロゲートは別集計です。収録率は単一コードポイントの判定で、異体字列・絵文字列の表示対応を保証しません。

### 編集バッファのカバレッジ

編集バッファの「カバレッジ」は、対象文字をすべて収録する端末フォントを一覧表示します。取得を許可したフォントを調べ、名前・スタイル・PostScript 名と、そのフォントで描画した対象テキストのプレビューを50件ずつ表示します。「解析」で選択したフォントをフォントタブへ読み込めます。名前での絞り込み、進捗、中止、再検索に対応します。判定は文字単位で、改行などの制御・表示調整用文字を除きます。異体字列・絵文字列・合字の表示対応の判定は別です。

### フォントの選択と読み込み

- フォントの表示名・ファミリー名・スタイル名はアプリの UI 言語（日本語・英語）を優先し、なければ英語を使います。どちらにも表示名がない場合は PostScript 名で識別します。カバレッジ一覧、端末フォント選択、コレクションのフェイス選択、解析画面で同じ方針を使います。
- フォントタブ左側の一覧から、名前・スタイル・PostScript 名で検索して直接選択できます。端末フォントは列挙後すぐに表示し、表示名の取得中も選択できます。↑↓・Home / End・Page Up / Down で移動し、Enter で解析します。
- 「端末フォント」と「読み込んだファイル」を見出しで分け、一つの領域でスクロールできます。端末フォントへ切り替えても読み込んだファイルは残り、その各フェイスへ戻れます。端末フォントのコレクションは一覧から直接選び、別のコレクション一覧は表示しません。狭い画面では「フォント一覧」から同じ一覧を開きます。
- コレクションでは選択フェイスを解析・表示・PNG 出力に共通して使い、端末フォントから選んだ場合は PostScript 名に一致するフェイスを開きます。可変フォントは PostScript 名に一致する名前付きインスタンスの名前・ウェイトで解析・表示します。
- 読み込み中は直前の解析対象と一覧の名前・スタイルを表示し続け、固定の領域で解析状況を示します。読み込み完了の通知は表示しません。
- 表示できない形式は画面に明示し、入力欄・文字コードの一覧に標準フォントを使い、文字からの PNG 出力は無効にします。Glyph ID からの輪郭表示・SVG / PNG 保存は利用できます。

## 小型画面

小型ノート PC（1024×600〜1366×768）では検索・文字表・編集バッファを同時に表示し、文字表と文字情報を個別にスクロールできます。「表示設定」にフォント・文字サイズ・色分け、「ブロック一覧」にブロック絞り込み・予約面表示をまとめています。「文字検索」では条件追加欄を折りたたんでも条件チップを確認できます。狭い画面ではツール選択をプルダウンにし、文字・絵文字の詳細をダイアログで開きます。[画面設計](ui-design.md)も参照してください。
