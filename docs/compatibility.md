# BabelMap との対応状況

2026-09-25 / Mojidata Map 0.1.0。基準は `docs/specification.md` の PE 解析結果と公式ヘルプ。**完全互換を表明するものではない。**

「実装」は該当する範囲のコードがあり、主要な操作を検証したことを表す。「一部」は下記の差分が残る。OS 固有機能は Web の仕様と区別する。

| 領域 | 状態 | 実装・差分 |
| --- | --- | --- |
| Unicode データ | 実装 | 18.0.0 正式版。参照バイナリは 17 ベータなので内容が完全一致するとは限らない |
| 全面・ブロック閲覧 | 実装 | U+0000–U+10FFFF、17 面、353 ブロック、予約面、ページ描画、拡大、未割当表示切替 |
| 文字検索・移動 | 実装 | 英語名・正式別名、文字入力、16/10進、NCR・UCN 入力、編集バッファ F2、Worker 検索 |
| 詳細検索 | 一部 | 文字検索の縦タブで条件を追加し、チップで確認・解除。一般カテゴリ、Script、Age、Block、面、複数の二値属性、Bidi、CCC、漢字の部首・枝番・内画数・総画数・読みを AND で組み合わせる。複数値 OR、正規表現、注記の検索などは未対応 |
| 文字情報 | 一部 | 基本属性、ケース写像、数値、分解、符号化、二値/列挙属性、別名、NamesList 注記。全 UCD XML フィールドとの網羅性は未保証 |
| 編集バッファ | 一部 | コピー・切り取り・手動貼付け・クリア・直前状態へ戻す、大小文字、正規化、方向、文字単位表示。RTF と BabelMap の Glyph mode は未対応 |
| 出力表現・保存 | 一部 | 文字、NCR hex/dec、HTML、UCN、JavaScript、UTF-8/16/32 表現。保存は UTF-8/16LE/16BE と BOM。HTML の名前付き参照は基本5種、他は数値参照。UTF-32 バイナリ保存・改行変換・RTF は未対応 |
| 漢字部首・読み検索 | 一部 | Unihan kRSUnicode（枝番の区別に対応）、総画数（kTotalStrokes と kAlternateTotalStrokes のいずれかに一致）、普通話・広東語（声調を無視）、チワン語、英語の意味。声調ごとの絞り込み、簡繁変換、国別ソースの複合検索は未対応 |
| 漢字詳細 | 一部 | Unihan に収録される全フィールドを文字ごとに遅延読込。BabelMap 独自の IDS/資料は未収録 |
| 彝文字部首検索 | 未対応 | 文字名・Script・Block による通常検索は利用可能 |
| 西夏文字の専用資料・検索 | 未対応 | 正式名・Script・Block による通常検索は利用可能 |
| エジプト文字の Unikemet | 未対応 | 正式名・基本属性は利用可能 |
| 絵文字 | 実装 | 独立したシーケンス検索タブで表示。文字と同位置のプレビュー、追加・コピー。Emoji 18 の fully-qualified 3,963 シーケンス。名前・グループで絞り込み、肌色・国旗・ZWJ を文字列として保持。描画はインストール済みフォントに依存 |
| 異体字列 | 一部 | StandardizedVariants と emoji variation sequences。IVD は未収録 |
| Unicode 統計 | 一部 | 現在版のブロック・Script・Age・面別収録数、TSV 出力。過去版ごとの属性履歴は未対応 |
| フォント選択・追加 | 一部 | CSS フォント名入力、対応環境で Local Font Access、TTF/OTF/WOFF/WOFF2/TTC 等の解析。通常表示はブラウザのフォールバックを許容 |
| 合成フォント | 一部 | ブロックごとに表示フォントを指定・保存。BabelMap の XML 互換、カバレッジ自動設定は未対応 |
| フォント解析 | 一部 | メタデータ、cmap の文字集合、ブロック別収録、選択文字の glyph ID。フォントの全内部テーブル・全インストールフォントの一括カバレッジ検査は未対応 |
| コレクションフォント | 一部 | フェイスを選んで解析可能。ブラウザ表示には先頭のフェイスを使う。フォント形式によって表示のみ失敗する場合は解析と分けて通知 |
| 字形出力 | 一部 | 選択字形の単色 SVG 輪郭、通常表示の透過 PNG。PNG はフォールバックを含む。バッチ出力、カラー字形の厳密なレイヤー出力は未対応 |
| OpenType | 一部 | fontkit の機能タグ指定、グリフ ID と位置の一覧・JSON 出力。最大1,000 UTF-16単位を解析し、一覧は先頭300グリフ。GSUB/GPOS の内部処理ログや Windows Uniscribe との一致は未保証 |
| データ生成・出力 | 一部 | 再現可能な公式データ生成、文字情報 JSON、検索結果 TSV。BabelMap の UCD/XML 出力形式は未対応 |
| ブックマーク・設定 | 一部 | ローカル保存、配色、文字サイズ、色分け、ブロック別フォント。設定のインポート/エクスポートや任意配色編集は未対応 |
| アプリ情報・クレジット | 実装 | アプリ / Unicode / Emoji の版、出典・謝辞、本番依存ライブラリと同梱ライセンス。アプリメニュー・デスクトップのヘルプメニューから表示 |
| Windows ウィンドウ操作 | 一部 | 画面の作業領域に収まる Electron 起動、最前面切替、標準編集メニュー。システムトレイ・自動起動は未対応 |
| Windows 配布 | 一部 | x64 ZIP の生成を Linux で確認。Windows 実機の描画・権限・操作は未検証。Windows CI を定義済みだが未実行 |
| Web / Linux / macOS | 一部 | Web と Linux Electron の主要操作を検証。macOS 実機は未検証。Web の永続オフラインキャッシュは未対応 |

## Unicode とフォントの取り扱い

- サロゲートは表示用情報として閲覧できるが、文字の挿入・コピー・保存では Unicode scalar value のみを受け付ける。
- 非文字・私用・未割当は区別して情報表示する。
- 正規化・大文字小文字・書記素分割は実行環境の Unicode 実装を利用する。表示用 UCD の版が 18.0.0 であっても、ブラウザの処理系の版が同一とは限らない。
- 通常の字形表示、カラー絵文字、複雑な書記体系の整形は Chromium/ブラウザと OS のフォントに依存する。BabelMap の WinGDI/Uniscribe と同じ結果を保証しない。
- 追加フォントはセッション内のみ保持する。再起動時に再読み込みが必要。

## 次の開発単位

1. Windows 実機/CI で Unicode 補助面、IME、フォント列挙、COLR/CPAL、保存・クリップボードを確認する。署名・インストーラー・アプリアイコンを整える。
2. 文字表/バッファの厳密な Glyph mode、フォールバックの制御、インストール済み全フォントのカバレッジ検査を実装する。
3. IVD と Unikemet、漢字ソース検索・声調、専門資料の出典と再利用条件を確認したうえで彝文字・西夏文字ツールを追加する。
4. 過去 UCD の差分・文字履歴、UCD/XML 互換出力、RTF、合成フォント設定のインポート/エクスポートを追加する。
5. トレイ、設定管理、Web のオフラインキャッシュと配布を整える。

各項目で必要な入力データと検証対象を揃え、実装・検証・日付別開発記録を一つの作業単位にする。
