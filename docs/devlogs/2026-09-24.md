## 環境上の制約

- 標準サンドボックスは `/mnt/wslg/distro` の bind mount 構成エラーで、読み取りコマンドも起動できない。実行コマンドは必要に応じて昇格モードを使用。
- Windows / Wine はこの環境にはない。Windows の操作検証は別途必要。

## Unicode データ基盤

- Unicode 17.0.0 の公式 UCD / Unihan / Emoji を取得し、URL・SHA-256 を `tools/unicode-sources.json` に固定。ライセンスを同梱。
- 346 ブロック、40,555 属性レコード、45,784 名前範囲、102,998 Unihan 文字、3,944 絵文字列を生成。Unihan 詳細は範囲ごとに分割。
- コードポイントの境界、公式派生名、属性検索、別名、UTF-8/16/32・NCR・UCN、漢字検索を実装。検索 Worker を分離。
- 検証: 6 件の単体テストが成功。全範囲テーブルの順序・重複、補助面、サロゲート、不正入力、部首残画を確認。初回テストの「漢」の期待残画数を、正式データの `85.11` に修正した。
- 依存を npm lockfile に固定。インストール時の audit は脆弱性 0 件。

## Web / デスクトップの初期実装

- React + TypeScript の日本語 UI を実装。全 Unicode 面、ブロック、ページ単位の文字表、キーボード移動、色分け、拡大、未割当表示、文字情報、ブックマーク、配色を追加。
- 名前・別名・コードポイント検索と属性の AND 絞り込み、Unihan の部首残画・読み・英語の意味検索、絵文字列の検索・挿入を実装。
- 編集バッファに挿入・コピー・切り取り・元に戻す・F2 位置検索・正規化・大小文字・方向・各種符号化・UTF-8/16 保存を実装。設定と編集内容を端末に保存。
- フォントファイルの読み込み・解除、cmap 収録範囲、メタデータ、単色 SVG 輪郭、表示の PNG、OpenType のグリフ ID/位置、ブロック別フォント設定を実装。フォント解析の状態をタブ切替後も保持。
- Electron は専用ローカルプロトコルで同梱ファイルを配信し、renderer の Node 権限を無効化。IPC はメインフレームとオリジン・入力型を検査し、コピーと最前面切替に限定。
- README に起動・ビルド・検証・データ生成の手順を追加。`docs/compatibility.md` に機能単位の対応範囲と未対応差分を明記。
- GitHub Actions に Web 検証と Windows 上の起動検証・ZIP 生成を定義。remote がないため、ワークフローの実行・公開・push はしていない。

## 検証と修正

- `npm run build`: TypeScript 型検査と Vite 本番ビルド成功。
- `npm test`: 8 件成功（Unicode/符号化/漢字 6 件、デスクトップのオリジン・パス境界 2 件）。
- `npm run test:e2e -- --workers=1 --reporter=line`: Chromium の操作テスト 8 件成功。検索 Worker、補助面、保存、ブックマーク復元、Unihan、ZWJ 絵文字、正規化、サロゲート拒否、モバイル幅、実フォント読込と SVG を確認。
- `xvfb-run -a node tools/smoke-desktop.mjs`: Linux の Electron で起動、専用プロトコル、Worker 検索、コピー、Node API の非公開、最前面切替を確認。Local Font Access が提供される環境では列挙も確認する。
- Playwright の Electron 起動はテスト用に Chromium sandbox を無効化する。製品コードの設定は sandbox を有効化しているが、OS sandbox 自体の動作確認とは区別する。
- `npm run format:check`: 成功。
- `tools/build_unicode.py` の再実行で、生成データ 34 ファイルがバイト単位で一致。
- `tools/capture-ui.mjs` で 1440px / 390px 幅の画面を撮影・目視確認。`var/screenshots/` に保存（バージョン管理外）。ブロック見出しと選択ブロックへのスクロール、モバイルのブロック選択を改善。
- Worker の本番データ URL、詳細検索のアクセシブル名、IPC を待つチェックボックスの状態更新、追加フォントのタブ間保持を、テストで見つけて修正した。
- この環境では未使用ポートへの接続が即座に拒否されず待ち続けるため、Playwright のサーバー待機を起動ログの検出へ変更。
- Electron 44 のランタイムは `npx install-electron` で取得。VS Code から継承する `ELECTRON_RUN_AS_NODE` は smoke 子プロセスの環境から除外。
- Jujutsu の新規ファイル 1 MiB 制限で一部生成データが初回コミットに含まれなかったため、確認済みサイズに合わせたコマンド単位の上限指定で追加コミットした。
