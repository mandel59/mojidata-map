## 配布物調査・仕様・技術選定

- 標準 Python のみを使用する `tools/analyze_babelmap.py` を追加。
- PE リソースから Unicode 17 ベータ版、7 メニュー、74 ダイアログ、57 文字列表を確認。
- 機能と根拠のリソース ID、SHA-256、解析の限界を `docs/specification.md` に記録。
- 公式ページと照合し、Electron + React + TypeScript / Vite、Unicode 17 正式データの構成を選定。比較理由は `docs/architecture.md`。
- 検証: 解析スクリプトが配布 ZIP から正常終了し、バージョン・メニュー・ダイアログ情報を出力。

## 環境上の制約

- 標準サンドボックスは `/mnt/wslg/distro` の bind mount 構成エラーで、読み取りコマンドも起動できない。実行コマンドは必要に応じて昇格モードを使用。
- Windows / Wine はこの環境にはない。Windows の操作検証は別途必要。
