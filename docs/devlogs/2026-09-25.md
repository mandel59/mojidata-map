# 2026-09-25 開発記録

## 検索導線と画面の整理

- `docs/instructions/initial.md` に従い、BabelMap 相当の機能を追加できる検索画面へ再構成。主対象は引き続き 1024×600〜1366×768 の小型ノートPC。
- ユーザーの最終指定に合わせ、トップレベルを「文字マップ」「文字検索」「シーケンス検索」「フォント」「Unicode データ」「ブックマーク」とした。文字検索内の文字／絵文字タブや検索方法ドロップダウンは設けない。
- 面・ブロック・コード指定は文字マップだけに表示。「一覧」は全面のブロック、ドロップダウンは選択中の面という従来指定を維持した。
- 文字マップの簡易検索から文字検索へ移動する。通常のタブ切替では検索条件・結果・ページ・選択・入力中の検索文を保持し、Ctrl/Cmd+F で文字検索へフォーカスを移す。
- 文字検索に条件カテゴリの縦タブと追加フォームを設置。文字分類、Unicode の範囲、文字の性質、名前の照合、部首・画数、読み・意味の6カテゴリ。適用した条件はチップで表示し、個別解除・全解除が可能。同じ項目は値を置換し、異なる項目は AND で組み合わせる。
- 漢字検索を文字検索の条件へ統合。部首・内画数・読みと Unicode 属性を同じクエリで組み合わせる。日本語表記は追加指示に従い「内画数」に統一し、ヘルプ・現行仕様も更新した。過去の日付の記録は当時の記述を保持。
- 追加指示に従い、タブと重複する「文字検索」の見出しと専用ツールバーを削除。「表示設定」を検索欄・検索ボタンと同じ段の右端へ移し、結果に使える高さを増やした。
- 1024px 以上では条件追加欄を結果の左へ配置。狭い画面では上へ移し、折りたたみ可能とした。適用済みチップは追加欄を閉じても残る。結果の列数は実際の領域幅に応じて16列／8列となり、矢印移動の量も合わせる。

## シーケンスとプレビュー

- シーケンス検索は現在、Emoji 18 のデータを使用。将来の標準化異体字列・IVS/IVD 等の追加先として設計し、未実装の資料を利用可能とは表示しない。
- 絵文字一覧内のプレビューを移し、文字マップ・文字検索と同じ右側に配置。狭い画面では結果の下に選択表示を置き、詳細をダイアログで開く。
- コードポイント列・名前・属性一覧を受け取る `SequenceDetails` を追加。ZWJ・肌色・国旗等を含む列全体を追加・コピーする。絵文字一覧の選択判定も、同名の別シーケンスを区別できるコードポイント列で行う。

## 実装の分離

- `SearchWorkspace`、`CharacterConditions`、`ConditionChips`、`SearchField` を分離し、旧 `AdvancedSearch` を置き換えた。検索結果とブックマークは `CharacterCollection` を共有する。
- `useCharacterSearch` が検索条件・結果・ページ・選択と Worker 通信を担当。要求IDで古い応答を無視し、Unihan 索引の読込待ち中に新しい検索を実行しても結果が逆戻りしない。
- Worker は漢字条件がある場合だけ索引を読む。先に Unihan で候補コードポイントを絞り、その候補へ Unicode 条件を適用する。通常の検索では漢字索引を読み込まない。
- Unicode の整数・範囲配列による内部表現、ページ間のセルDOM再利用、文字サイズの局所 state / Context による更新分離を維持した。
- `docs/ui-design.md` に画面の役割・操作・小型画面への対応・将来機能の追加先を整理し、README、アーキテクチャ、互換性表を更新した。
